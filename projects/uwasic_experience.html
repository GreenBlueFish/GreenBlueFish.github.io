Digital

Overview

During my 3rd co-op term (right after 2A) I decided to join UW ASIC. The digital team was building a 10G ethernet parser. I decided to join but first had to complete a digital team onboarding. The project was writing an spi peripheral that integrated with an already made pwm peripheral. The code of that can be found here

Onboarding

The onboard project involved taking in a one bit data line and clock from an attached device. Then writing some code for a cross clock domain to be able to receive the data on the systems clock signal. Then I had to load a buffer with the data and decoding it. The first bit indicated read or write, the next three bits indicated a specific register, and the last 8 bits were data for a register. The register values were then read by an pwm module that produced a pwm signal based on the register value. Apart of the onboarding was also to write test code in python using the cocotb libaray. This involved writing signals to the device and testing results were within an acceptable threshold
