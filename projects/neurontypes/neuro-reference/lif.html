MODEL 01
Leaky Integrate-and-Fire

The simplest spiking neuron model. Integrates input current with a passive membrane leak and fires when voltage crosses a threshold, which is then instantaneously reset. The analytical tractability of the LIF makes it the foundation of mean-field theory and the default substrate for STDP studies.

ODEs1
Spike PrecisionHigh
Dendritic EffectsNone
Computational CostVery Low
Biological FidelityLow

Governing Equation

Membrane Voltage
τm · dV/dt = −(V − Vrest) + R · I(t)
SymbolDescriptionTypical
τmMembrane time constant — controls passive decay speed10–20 ms
VMembrane potential (state variable)mV
VrestResting membrane potential−65 to −70 mV
RMembrane resistance — scales input current effect10–100 MΩ
I(t)Total input current (synaptic + external) at time tpA

Reset Mechanism

Threshold & Reset
if V ≥ Vthresh : emit spike, V ← Vreset, hold for tref ms
SymbolDescriptionTypical
VthreshSpike threshold — voltage that triggers a spike−55 mV
VresetPost-spike reset voltage (can model AHP by setting below rest)−65 mV
trefAbsolute refractory period — neuron cannot fire during this window2–5 ms
Key insight: The reset is discontinuous — V jumps instantaneously. This is biologically unrealistic (real spikes take ~2 ms) but computationally convenient and negligible for most STDP questions where inter-spike intervals ≫ spike width.

Online Trace Implementation for STDP

STDP is implemented via exponentially decaying eligibility traces that are updated at each spike:

Pre/Post Traces
dx/dt = −x/τ₊ → x ← x + 1 at each pre-spike
dy/dt = −y/τ₋ → y ← y + 1 at each post-spike
At post-spike: w ← w + A₊ · x
At pre-spike: w ← w − A₋ · y

Characteristics

PropertyDetails
Spike precisionHigh — spikes are instantaneous, unambiguous, deterministic events
Dendritic effectsNone — single-compartment point neuron; all inputs collapse to soma
Cost (time step)Very low — explicit Euler stable at Δt = 0.1–1 ms
Biological fidelityLow — no spike shape, no adaptation, no realistic aftercurrent
STDP suitabilityExcellent — Δt is perfectly defined; default model for STDP theory
Common usesLarge network simulations, STDP analysis, mean-field theory, neuromorphic hardware

Advantages

  • Analytically tractable — closed-form solutions for Poisson inputs
  • Computationally trivial — ideal for networks of 10⁴–10⁶ neurons
  • Natural substrate for STDP — spike times are exact
  • Well-studied — decades of theoretical results available

Limitations

  • No spike shape — threshold crossing is artificial
  • No adaptation — cannot reproduce spike frequency adaptation
  • No subthreshold resonance — misses important dynamics
  • Reset is biologically unrealistic — discontinuous jump
