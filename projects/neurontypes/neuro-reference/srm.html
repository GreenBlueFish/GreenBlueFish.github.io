MODEL 08
Spike Response Model (SRM)

A kernel-based formulation where membrane voltage is expressed as a superposition of response kernels convolved with past spike times — no ODE integration required. Spikes are events; the membrane trajectory between spikes is deterministic. Natural framework for theoretical STDP analysis and population density methods.

Kernel Definitions

Standard Kernel Forms
η(s) = −Vthresh · exp(−s/τref) for s > 0 [afterpotential]
ε(s) = (τm/C) · exp(−s/τm) for s > 0 [alpha-function PSP]

Kernels can be fitted to match any neuron type. The α-function ε approximates a biexponential EPSP. More complex kernels with multiple exponentials can match dendritic filtering.

Reset Mechanism

Reset is encoded in the η kernel — no discontinuous jump is needed. Immediately after a spike (small s), η(s) is strongly negative, holding V below rest. As s grows, η decays back to zero, recovering excitability:

Key insight: The refractory period is not a hard rule but a continuous effect of η. Absolute refractoriness (η → −∞) and relative refractoriness (η slowly recovering) are both captured by the kernel shape. This makes STDP analysis elegant — the full post-spike voltage trajectory is in closed form.

STDP in the SRM Framework

Because V(t) is a linear superposition of kernels, STDP weight updates can be written in closed form. The Hebbian trace is directly the ε kernel:

STDP Weight Update (SRM)
Δwⱼ = A₊ · Σ_f ε(tpost − tⱼ⁽ᶠ⁾) evaluated at post-spike
Δwⱼ = −A₋ · Σ_g η(tⱼ(g) − t̂) evaluated at pre-spike

Advantages

  • No ODE integration — analytically exact between spikes
  • STDP weight changes have closed-form expressions
  • Natural basis for Bayesian and information-theoretic STDP analysis
  • Population density methods are directly applicable

Limitations

  • Kernels must be specified a priori — less mechanistic than HH
  • Cannot model nonlinear dendritic computation
  • Stochastic extension (SRM₀) requires escape rate functions
