STDP 10
Surrogate Gradient Methods

Enable backpropagation through non-differentiable spike events by replacing the Heaviside step function's zero derivative with a smooth surrogate during the backward pass. Currently the state-of-the-art approach for training deep SNNs on complex tasks such as image classification and speech recognition.

TypeSupervised
DepthDeep SNNs
CostHigh
StabilityGood
Bio. PlausibilityLow

The Core Problem

Why standard backpropagation fails for SNNs:
A spike is generated by the Heaviside step function H(V − Vthresh):
• H(V − Vthresh) = 1 if V ≥ Vthresh else 0
• dH/dV = 0 everywhere (except at threshold where it is undefined)

Zero gradient means no learning signal can propagate through spike events. Backpropagation through time (BPTT) computes ∂L/∂V at each timestep — but if ∂z/∂V = 0, the gradient vanishes at every spike.
Forward vs. Backward Pass
Forward: z = H(V − Vthresh) [true, binary spike]
Backward: dz/dV ≈ σ'(V − Vthresh) [smooth surrogate]

Common Surrogate Functions

Surrogate Choices
Sigmoid: σ'(x) = β · σ(β·x) · (1 − σ(β·x))
Fast sigmoid: σ'(x) = 1 / (1 + β·|x|)²
Piecewise linear: σ'(x) = max(0, 1 − |x|/β)

BPTT in SNNs

Gradient Propagation
∂L/∂V_t = ∂L/∂z_t · ∂z/∂V_t + ∂L/∂V_{t+1} · ∂V_{t+1}/∂V_t

The first term uses the surrogate; the second propagates through the LIF membrane dynamics. This is unrolled across all T timesteps — equivalent to BPTT in a recurrent network with T = simulation duration / dt.

Advantages

  • Achieves near-ANN accuracy on ImageNet, DVS gesture, speech benchmarks
  • Compatible with PyTorch/JAX autograd — surrogate is a one-line change
  • Enables training of multi-layer deep SNNs — not possible with STDP
  • Well-studied — convergence properties understood from RNN literature

Limitations

  • Not biologically plausible — requires global gradient signal and weight transport
  • Full BPTT is expensive — must store all voltages across T timesteps
  • Surrogate choice is a heuristic — different surrogates give different results
  • Gradient may vanish or explode over long time sequences (same as RNNs)
