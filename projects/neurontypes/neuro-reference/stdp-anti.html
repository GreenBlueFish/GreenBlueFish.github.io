STDP 05
Anti-STDP

The sign of the classical STDP learning window is reversed: pre-before-post causes LTD, and post-before-pre causes LTP. This anti-Hebbian rule implements predictive suppression — the synapse weakens connections that are causally reliable, effectively canceling predictable inputs. Found experimentally in the electric fish electrosensory lateral line lobe.

TypeAnti-Hebbian
Traces2
CostVery Low
StabilityCircuit-Dependent

Learning Rule

Reversed STDP Window
Δw = −A₊ · exp(−Δt/τ₊) if Δt > 0 [pre before post → LTD]
Δw = +A₋ · exp(Δt/τ₋) if Δt < 0 [post before pre → LTP]
Compare to classical: In classical STDP, positive Δt (causal order) → LTP. In anti-STDP, positive Δt → LTD. The network learns to suppress connections that repeatedly predict future postsynaptic firing — the opposite of causal reinforcement.

Predictive Cancellation Function

Anti-STDP implements a negative feedback loop: if presynaptic cell A reliably fires before postsynaptic cell B (a causal pattern), the connection A→B weakens. This reduces B's response to A's input, suppressing the predicted signal. Only novel, unpredicted inputs that break the temporal pattern remain effective.

Advantages

  • Natural mechanism for sensory cancellation — cancels expected, not novel input
  • Biologically documented in specific systems
  • Can coexist with standard STDP to implement predictive coding
  • Same computational cost as classical STDP

Limitations

  • Destabilizing for generic excitatory cortical networks
  • Applicable only to specific circuit types — not a general learning rule
  • Rarely a default choice — requires careful circuit context
  • Interaction with classical STDP in mixed networks is complex
