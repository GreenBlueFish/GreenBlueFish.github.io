MODEL 07
Morris-Lecar Model

A conductance-based model with Ca²⁺ and K⁺ currents, originally derived for barnacle muscle fiber. The fast Ca²⁺ activation is treated as instantaneous (m∞), leaving only one gating ODE for K⁺. Supports both Class I and Class II excitability by parameter choice — critical for models where calcium dynamics underlie STDP.

Reset Mechanism

No explicit reset. The spike arises from Ca²⁺ current activation (fast, via m∞) and terminates via K⁺ gate opening (slow, via w). Class I vs Class II excitability is set by the relative positions of the nullclines:

Excitability ClassOnsetMinimum Firing RateSTDP Use
Class IVia saddle-node bifurcationArbitrarily low (0 Hz+)Rate-modulated STDP; continuous frequency control
Class IIVia Hopf bifurcationNon-zero minimum (~10 Hz+)Oscillatory STDP; phase locking

Why Morris-Lecar for STDP

Ca²⁺ hypothesis of STDP: The direction and magnitude of synaptic change depends on postsynaptic Ca²⁺ concentration. High Ca²⁺ (from NMDA + VGCC coincidence) → LTP; moderate Ca²⁺ → LTD. Morris-Lecar explicitly models Ca²⁺ current, making it the preferred substrate for studying how membrane dynamics shape the Ca²⁺ signal that drives plasticity.

Advantages

  • Explicit Ca²⁺ current — directly links to STDP calcium hypothesis
  • Two excitability classes — tests STDP under different spike onset dynamics
  • Analytically similar to FHN but with biophysical conductance interpretation
  • Phase-plane techniques fully applicable

Limitations

  • Derived from barnacle muscle — not directly a cortical neuron model
  • Parameters require fitting to specific preparations
  • No adaptation — cannot reproduce firing pattern diversity
