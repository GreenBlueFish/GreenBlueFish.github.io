STDP 01
Classical Additive STDP

The foundational spike-timing-dependent plasticity rule, experimentally confirmed by Bi and Poo (1998) in cultured hippocampal neurons. Synaptic strength increases when the presynaptic neuron fires before the postsynaptic neuron (LTP) and decreases in the reverse order (LTD), with the magnitude decaying exponentially with the inter-spike interval.

TypeUnsupervised
Traces2
CostVery Low
StabilityPoor
Bio. PlausibilityHigh

Learning Rule

STDP Window
Δt = tpost − tpre
Δw = A₊ · exp(−Δt/τ₊) if Δt > 0 [pre before post → LTP]
Δw = −A₋ · exp(Δt/τ₋) if Δt < 0 [post before pre → LTD]
SymbolDescriptionTypical
ΔtInter-spike interval (t_post − t_pre). Positive = pre fires firstms
ΔwSynaptic weight change—
A₊Maximum LTP amplitude0.01–0.1
A₋Maximum LTD amplitude. Usually slightly > A₊ for stability0.01–0.12
τ₊LTP time constant20 ms
τ₋LTD time constant20–40 ms

Online Trace Implementation

Eligibility Traces
dx/dt = −x/τ₊ → x ← x + 1 at each pre-spike
dy/dt = −y/τ₋ → y ← y + 1 at each post-spike
At post-spike: w ← w + A₊ · x
At pre-spike: w ← w − A₋ · y
Local implementation: Each synapse maintains two numbers: x (pre trace) and y (post trace). No global information needed. This is why STDP is attractive for neuromorphic hardware — O(1) memory and computation per synapse per spike.

Causal Interpretation

If pre fires at t=0 and post fires at t=+5ms, the pre trace x is still elevated when the post spike arrives → weight increases. If post fires first (t=0) and pre fires later (t=+5ms), the post trace y is elevated when the pre spike arrives → weight decreases. STDP thus reinforces causal connections.

Advantages

  • Fully local — only pre and post spike times required
  • Biologically confirmed in multiple brain regions and species
  • Naturally learns causal temporal sequences
  • Analytically tractable — closed-form solutions for Poisson inputs

Limitations

  • Additive updates → bimodal weight distributions (all-high or all-low)
  • Unstable under high firing rates without normalization
  • Pair-based — ignores burst interactions captured by triplet rule
  • No credit assignment across multiple layers

Stability Analysis

For Poisson presynaptic inputs with rate rpre, the mean weight change per unit time is:

Expected Weight Change
dw/dt ∝ A₊·τ₊·rpre·rpost − A₋·τ₋·rpre·rpost
= rpre·rpost·(A₊·τ₊ − A₋·τ₋)

Stability requires A₋·τ₋ > A₊·τ₊ (net LTD dominance). In practice this means A₋ > A₊ when τ₊ ≈ τ₋, or τ₋ > τ₊ when A₊ ≈ A₋.
