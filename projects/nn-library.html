Motivation

Why I built this

Neural Network 1

I wanted to understand how neural networks work from first principles. I decided (foolishly so) to make my own neural network library so I could implement forward and back propagation by hand as well as all other functions needed to implement a neural network. I did not use any generative AI for this project. All programming, debugging and design was done by me.

Neural Network 2

My second neural network was a do-over of the whole project. I thought the programming could be improved (from the lessons I learnt in my university programming class) and the whole architecture could be modified so that I could implement a few ideas I had that at the time seemed unique.

Approach

How I built it

Neural Network 1

The library was built around a central Neural_Network class, which provided the core interface for creating, training, and modifying neural network architectures. The framework included a broad set of built-in features such as:

  • Dynamic Layer Creation and Removal
  • Dynamic Node Creation and Removal
  • Forward Propagation and Backpropagation
  • Custom Activation Functions and Softmax Support
  • Discrete Number Processing Functionality
  • Binary Serialization and Deserialization (.ppm image support)
  • Text-Based Save and Load Features
  • Network Visualization and Print Utilities

Beyond the core framework, I developed several experimental tools focused on neural architecture optimization and automated testing.

One utility could evaluate permutations of activation functions across nodes and layers, allowing different activation strategies to be benchmarked against a given architecture and dataset.

I also created an automated architecture generation system that began with a minimal network structure and iteratively modified hidden layers and activation functions to minimize cost while working within fixed training and testing dataset constraints.

Additional tooling included:

  • Training and testing dataset generation from arbitrary mathematical functions
  • 2D binary map classification systems for coordinate-based learning problems
  • Automated network experimentation and evaluation utilities

Neural Network 2

After graining a strong foundation in neural networks I decided to build a more capable library that would allow me to experiement with many different NN architectures that I came up with (as it turned out none of these were origional) I wanted to be able to have a lot more control over individual nodes. Allowing me to edit their individual activation function (not just as a layer like in my first NN) and to edit where they connect. I wanted to allow weighted (or unweighted) residual learning, allow multple networks to connect, allow for variable activation functions (which I am very interested in), and to allow for anynode to have it's own cost function (I know this seems weired but the idea was that I could make the neurons function more like a neuron if I could evaluate them to some constant value and cause disturbances to learn, I still need to research more into that). FINISH!!!!

Results

Outcomes

94% test accuracy on MNIST
2 library versions built

The library successfully trained on several benchmark datasets and served as the base for the map classifier and architecture search projects.

Reflection

What I learned

Implementing the backward pass manually made the chain rule click in a way that reading about it never did. I also gained a much better intuition for why vanishing gradients happen in deep networks with sigmoid activations.
